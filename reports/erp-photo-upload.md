# Photographs Unleashed is missing, staged for upload

Generated by `npm run report:photoupload`. Read-only against Unleashed.

**The API cannot upload these.** `Images` is a GET-only field on Products —
it appears in no POST request body — and Unleashed's support notes images
cannot be bulk-loaded by CSV either. They go on the product record or into
the File Library by hand. Everything a machine can do is done here: the
files below are named after the ProductCode they belong to.

| | |
|---|---:|
| Size codes with no photograph in the ERP | **50** |
| Photograph recovered and staged | **24** |
| Quarantined — points at another size's photograph | 1 |
| No photograph in the snapshot at all | 24 |

Files: `reports/erp-upload-images/<ProductCode>.jpg` — gitignored (matches `reports/*-images/`).
